# Raw sources

Byte copies of original documents. **Nothing in this folder is ever edited, reformatted, renamed, or deleted**, including by the assistant, including to fix an obvious typo. If a document is wrong or superseded, it stays and the correction is recorded in its page under `wiki/sources/`.

New versions arrive as new files alongside the old ones. Provenance is the point.

Every file here should have a matching page in `wiki/sources/` that summarises it, cites it, and records what it superseded. If a file has no source page, it has not been ingested; run the `wiki` skill on it.

## What does not go here

Anything with a credential in it. Anything the user has not seen. Large binaries; link to them instead. Assistant-written synthesis, which belongs in `wiki/`, and confirmed facts, which belong in `records/`.
