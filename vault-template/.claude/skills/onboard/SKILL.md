# onboard

Read AGENTS.md and INDEX.md in the vault. Check existing interview records before asking questions. Ask one focused question at a time, prioritizing the biggest missing life areas. Save each answer immediately as a confirmed interview record with its date and source. Produce or update concise profile records from answers, preserving links to the interviews. Do not infer unprovided personal details. End with the most useful next question or a concrete work task supported by the new context.

Routes, record schema, and update rules are in the vault manual (AGENTS.md / CLAUDE.md). Preserve the record schema, run `npm run index` after direct edits, and never place credentials in records.
