# Implementation status

## Implemented
Local application and static production build; loopback Node API; Markdown knowledge records; per-record Git history and restore; optimistic edit conflict detection; search; 3D graph with real category/record nodes; explicit relationships; onboarding capture; imports and exports; deterministic audits; verified knowledge bundles; separate application/vault histories; Codex CLI advice and local-work integration; workflow skills; manual provider import adapters.

## Requires user setup
Account selection and scoped credentials; private off-device repository destinations; personal onboarding. Routines remain manual by explicit user choice. Codex assistant needs a working installed CLI and sign-in.

## Partial compared with the video
Provider imports are bounded, manual snapshots. Google/Microsoft OAuth refresh and full consent flows are not implemented. Fathom/Skool use manual exports. Community pulse has no ranking engine. Meeting/video transcripts need file import or another authorized connector. The 3D interface follows the video layout, but is not a pixel-exact reproduction. No external message sending or publishing is implemented in the dashboard.

These limitations must not be described as active connections or finished automation.
