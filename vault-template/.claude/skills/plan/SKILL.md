# plan

Retrieve current goals, preferences, tasks, calendar, and relevant project records. Check source dates; request missing critical deadlines or availability. Compare competing commitments and realistic time requirements. Explain priorities and tradeoffs, then create a concrete plan with tasks, dates, dependencies, and source links. Label estimates. Save the plan as an inference until accepted. Perform requested local deliverables, keeping external actions within the user's authorization.

Routes, record schema, and update rules are in the vault manual (AGENTS.md / CLAUDE.md). Preserve the record schema, run `npm run index` after direct edits, and never place credentials in records.
